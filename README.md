# АрⅤ播放器

酒馆助手音乐播放器的 GitHub 扩展版。

## 当前版本

V9.0.0

## 功能

- 浮动音乐播放器
- QQ 音乐歌单导入
- 音乐搜索与本地歌单
- 歌词显示与定位
- 播放模式切换
- 播放器主题与外观设置
- 自定义壁纸、模糊度与亮度
- 手机端布局与歌单横向滑动优化
- 本地数据保存在浏览器 `localStorage` 中
- 不包含网易云登录功能
- 不包含字体设置功能

## 安装

在 SillyTavern 的扩展管理中选择“安装扩展”，填入本仓库的 Git URL。安装后由 `manifest.json` 加载 `index.js`。

## 数据说明

播放器的本地歌单与设置保存在使用环境的浏览器本地存储中，不写入本 GitHub 仓库。

## 更新

后续版本通过 GitHub 提交更新，并在 `manifest.json` 中递增版本号。
