# 📖 使用说明

### 🎵 搜索歌曲

在输入框左侧切换音源/搜索模式。

进入搜索模式后：

> 输入歌名 → 点击搜索 → 在搜索结果中点击「➕」

即可将歌曲添加到歌单。

添加时可以选择指定歌单。

### 📂 歌单管理

播放器顶部可以新建、切换和管理歌单。

双击自定义歌单可以删除歌单。

已经导入或添加的歌曲会保存在浏览器本地，关闭酒馆或脚本后不会自动消失。

### 🎤 歌词

播放器支持歌词显示与定位。

如果不需要歌词显示：

> 打开播放器 → 再次点击「CC」

即可关闭歌词显示。

### 🖼️ 壁纸

进入播放器外观/设置后，可以添加自己的图片作为播放器壁纸，并调整壁纸模糊度与亮度。

壁纸数据保存在本地，不会随着 GitHub 仓库一起公开。

# 🐙 GitHub 扩展版

现在播放器已经整理为可通过 GitHub 仓库安装的 SillyTavern 扩展。

安装时请使用**整个 GitHub 仓库地址**，而不是单独的 `index.js` 或 `manifest.json`。

播放器的个人歌单、歌曲记录、设置及壁纸等数据保存在使用者自己的浏览器本地，不会写入本 GitHub 仓库。
